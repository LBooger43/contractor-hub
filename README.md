# Contractor Hub — Version 1

Invoices by text, job schedule, crew time clock, job profit, and Google Calendar links for every job. English and Spanish.

- `index.html` — the app (owner and crew sign in here)
- `bill.html` — the page customers open from the text to see and pay an invoice
- `demo.html` — a practice copy with pretend data; nothing is saved

Built from the Limpiempo Version 1 code. For now it uses the same Supabase project as Limpiempo (each business only sees its own data).
Supabase › Authentication › URL Configuration › Redirect URLs must include this site's address so sign-up emails come back here.
